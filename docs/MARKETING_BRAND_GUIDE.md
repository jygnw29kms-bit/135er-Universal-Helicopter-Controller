# 135er Heli Control — Brand & Marketing Guide

## Positioning

135er Heli Control is an open helicopter-control platform for serious simulator pilots.

It is not positioned as:
- a generic joystick
- a loose STL collection
- a GitHub experiment

It is positioned as:
- a complete helicopter-control system
- built around real helicopter control logic
- modular and serviceable
- contactless on all primary analog axes
- open by design

## Primary brand name

**135er Heli Control**

Product descriptor:
**Universal Helicopter Controller**

## Core promise

A complete helicopter-control system for simulator pilots: Cyclic, Collective, Anti-Torque Pedals and independent Toe Brakes — precise, contactless and open.

## Brand line

**Built for rotary flight.**

German supporting line:
**Vollständige Helicopter-Steuerung. Offen entwickelt. Für echten Rotary-Flight im Simulator.**

## Messaging hierarchy

1. Helicopter-specific control
2. Complete system
3. Precision/contactless sensing
4. Modular/serviceable construction
5. Compatibility
6. Open source / DIY build

Open source is an advantage, not the lead message.

## Tone

Use:
- precise
- calm
- technical
- aviation-oriented
- premium
- confident without overclaiming

Avoid:
- hobbyist slang
- exaggerated superlatives
- unvalidated performance claims
- developer jargon in primary marketing copy
- release/build numbers in hero messaging

## Visual direction

- near-black / graphite backgrounds
- cool cyan as primary accent
- restrained mint/green as secondary technical accent
- large typography
- generous negative space
- cockpit/instrument precision
- no neon cyberpunk overload
- no gamer RGB aesthetic

## Product modules

### Cyclic
Pitch and Roll.
Message: direct, low-friction control around bearing-supported steel pivots.

### Collective
Collective and Twist Throttle.
Message: helicopter-specific lever geometry with adjustable friction.

### Pedals
Anti-Torque Yaw and Toe Brakes.
Message: independent yaw plus separate left/right braking.

## Technical trust points

- 7 Hall-based analog axes
- RP2350 / Raspberry Pi Pico 2
- MCP3208 external ADC
- standard USB HID
- USB CDC configuration/diagnostics
- persistent calibration
- replaceable sensor and mechanical modules
- FDM-first structural parts combined with real steel shafts/bearings
