# Cyclic V1

## Baseline geometry

- Floor-mounted dual-gimbal cyclic
- Stick length from pivot: approx. 480 mm
- Pitch travel: approx. +/-15 deg
- Roll travel: approx. +/-15 deg
- Stick tube: 20-22 mm aluminium tube
- Main shafts: 8 mm steel
- Bearings: 608-2RS
- Base target: approx. 220 x 180 x 75 mm

## Sensor concept

Each axis uses a contactless magnetic angle sensor.

- Magnet mounted concentrically on the axis
- Replaceable printed sensor carrier
- No gears or linkages between shaft and sensor
- Target sensor gap: 1-3 mm depending on final sensor choice

## FDM rules

- PETG baseline
- Standard wall thickness: 3.2 mm
- Structural zones: 5-6 mm
- Moving PETG interfaces: 0.25-0.35 mm clearance
- Design for support-free orientation wherever possible
- Split large components into mechanically keyed screw-fastened parts

## V1 printed parts

- Base bottom
- Base left
- Base right
- Pitch gimbal
- Roll gimbal
- Stick clamp A
- Stick clamp B
- X sensor mount
- Y sensor mount
- Spring mounts
- Cover
- Grip halves

## Controls in the grip

- 4-way trim hat
- PTT
- Force-trim release
- Two spare buttons

## Centering

Three intended modes:

- Free: no centering springs
- Light: very soft centering
- Normal: stronger centering for joystick-like preference

Final spring geometry will be adjustable via slotted mounts.
