# FDM Printing Guide

Designed around a 256 x 256 mm class printer.

PETG baseline:
- 0.4 mm nozzle
- 0.20 mm layer height
- 4 perimeters
- 5 top and 5 bottom layers
- 30-40% infill
- 50% local infill for gimbal, lever root and pedal rocker if desired
- supports off by default

Print parts on their largest flat face. Fit-critical bearing pockets and shaft bores should be tested first if the printer is not dimensionally calibrated.
