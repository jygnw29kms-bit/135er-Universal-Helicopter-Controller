# Production Print Order V1.1

Only start this order after the validation coupons have fixed real printer/filament clearances.

## Stage 0 - fit validation
1. validation plate
2. bearing coupon if needed separately
3. shaft coupon
4. tube coupon
5. magnet coupon
6. fastener coupon

## Stage 1 - Cyclic
1. magnet hub
2. Hall sensor mount
3. stick clamp
4. inner gimbal
5. outer gimbal
6. split grip front/rear
7. cyclic base

Stop and assemble the complete Cyclic before continuing.

## Stage 2 - Collective
1. Hall sensor mount
2. friction adjuster
3. throttle grip halves
4. lever root
5. collective base

Stop and verify collective + throttle independently.

## Stage 3 - Pedals
1. Hall sensor mounts
2. toe brake left/right
3. pedal plates
4. rocker
5. pedal base

Stop and verify yaw and both toe-brake axes independently.

## Stage 4 - Electronics
1. controller tray
2. controller lid

The order intentionally prints fit-critical and low-filament parts before large structural parts.
