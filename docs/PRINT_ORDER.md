# Production Print Order

After the validation plate dimensions are frozen:

## Stage 1 - Cyclic
1. magnet hub
2. Hall sensor mount
3. stick clamp
4. inner gimbal
5. outer gimbal
6. cyclic base

Stop and mechanically assemble the Cyclic before printing the next module.

## Stage 2 - Collective
1. Hall sensor mount
2. throttle grip halves
3. lever root
4. collective base

## Stage 3 - Pedals
1. Hall sensor mount
2. pedal plates
3. rocker
4. pedal base

This order intentionally prints small fit-critical parts before large high-filament parts.
