# CAD

All mechanical modules are designed FDM-first.

## Directories

- cyclic/
- collective/
- pedals/
- grips/

## Design requirements

- Every printable part must fit a 256 x 256 mm bed
- Prefer support-free geometry
- Avoid long unsupported bridges
- Prefer screw-fastened assemblies over glued shells
- Use replaceable sensor carriers
- Use metal shafts and bearings for critical pivots
- PETG is the baseline material

Native CAD source files and export STL/3MF files will be added after validation.
