# Cyclic CAD

## First prototype scope

The first CAD iteration will contain:

- Base frame
- Roll gimbal
- Pitch gimbal
- Stick clamp
- Two Hall sensor mounts
- Optional spring mounts
- Top service cover
- Grip interface

## Export policy

For each validated revision, include:

- Native CAD source
- STEP
- STL
- Optional 3MF print project

## Print orientation

Every part should have an obvious flat orientation. Parts that require support should be redesigned unless there is a strong structural reason not to.

## Prototype naming

Use revision naming like:

```text
cyclic_base_v0.1
cyclic_roll_gimbal_v0.1
cyclic_pitch_gimbal_v0.1
cyclic_sensor_mount_v0.1
```
