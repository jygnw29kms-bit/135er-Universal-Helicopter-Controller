# Microsoft Flight Simulator profile

Suggested logical mapping:
- Cyclic Roll -> helicopter cyclic lateral / roll axis
- Cyclic Pitch -> helicopter cyclic longitudinal / pitch axis
- Collective -> helicopter collective axis
- Throttle -> helicopter throttle / engine control as required by aircraft
- Pedals -> rudder / anti-torque axis
- Toe brakes -> left/right brake axes

Keep firmware curves linear initially. Apply aircraft-specific sensitivity only after physical calibration.
